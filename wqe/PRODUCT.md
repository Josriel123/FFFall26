# Dinosaur Quiz

<!-- impeccable:product-schema 1 -->

## Platform

web

## Product Purpose

Complete the class assignment by changing the instructor's quiz questions and answers and styling the result with UIkit.

## Capabilities and Constraints

- Use the quiz in the instructor's arrayobjectfunctions folder as the starting point.
- Keep plain HTML, CSS, and JavaScript at the level of the approved course references.
- Use UIkit 3.24.2, the version in the instructor's UIkit example.
- Write grid columns explicitly, without repeat().
- Keep the existing root and Project1 pages unchanged.
- Publish at wqe/index.html, matching the submitted assignment link.

## Implementation Choices

The user delegated the assignment's content and layout. This quiz uses five dinosaur questions, native radio buttons, answer feedback, a score, and a restart. It follows the existing Dinosaur Guide's forest colors and Trebuchet typography.
