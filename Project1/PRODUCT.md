# The Dinosaur Guide

<!-- impeccable:product-schema 1 -->

## Platform

web

## Purpose

A creative dinosaur field guide for the Front End Fundamentals midterm. Readers learn about prehistoric periods and species and try simple JavaScript controls.

## Requirements

- Proper HTML document setup and semantic structure.
- At least five images with descriptive alt text and CSS styling; retain all six existing species illustrations.
- At least three styled HTML tags and three classes apart from grid classes.
- A gridded navigation and two distinct multi-column content grids.
- Responsive layouts and at least three interactive JavaScript elements.
- Keep the category filter, weight calculator, roar-description selector, and theme switch.
- Use the approved course examples and introductory HTML, CSS, and JavaScript. Write grid columns explicitly without repeat().
- Keep the existing AI concept and image attribution. The roar guide changes descriptions; it does not play audio.

## Existing Content

index.html contains the period summaries, species descriptions, image captions, calculator options, and footer. The images folder contains the six existing dinosaur illustrations. The separate space-explorer page is outside this work.
